Instrucciones

Aprende cómo jugar Puzzle Master y completar los diferentes rompecabezas.

¿Cómo jugar?

  1. Selecciona un nivel.
  2. Selecciona uno de los rompecabezas disponibles.
  3. Ordena las piezas utilizando el espacio vacío.
  4. Completa la imagen para superar el rompecabezas.

Movimiento de las piezas

Las piezas únicamente pueden moverse cuando se encuentran junto al espacio vacío.

Niveles

  • Nivel 1: tablero de 3 x 3.
  • Nivel 2: tablero de 4 x 4.
  • Nivel 3: tablero de 5 x 5.
